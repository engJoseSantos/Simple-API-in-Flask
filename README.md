# Simple-API-in-Flask

A simple cryptocurrency API built with Flask for learning purposes.
This provides crypto price data and includes a contact form with validation.

This project demonstrates:

REST API development with Flask
JSON responses
Basic input validation
Email regex validation
Template rendering
Clean project structure

Install dependencies:
pip install flask
