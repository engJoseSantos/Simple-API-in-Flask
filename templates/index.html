🚀 Crypto API

Simple Flask API that returns cryptocurrency prices in USD.

Available endpoints

  • /token/<code> – Get one crypto (example: /token/btc)
  • /tokens – List all available cryptocurrencies

Example response

{
    "id": 1,
    "name": "Bitcoin",
    "code": "BTC",
    "price_usd": 73550.97
}
